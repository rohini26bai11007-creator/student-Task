# Project Statement

**Project:** Student Task & To-Do Manager  
**Student:** Rohini Ghodeshwar  
**Language:** Python 3  
**Program type:** Command-line application

## Problem

Students receive tasks across different subjects and need a simple way to remember what is due and what has been completed.

## Aim

This program lets a student enter tasks and review them by title, subject, category and completion status. It also gives basic counts of all, pending and completed tasks.

## Scope

The program provides ten menu actions: add a task, view all tasks, search, mark a task completed, view pending tasks, view completed tasks, delete a task, organize by subject or category, show statistics, and exit.

Tasks are held in a Python list in memory for the current run. This beginner version does not save tasks after the program closes.

## Learning objectives

- Practice Python input, output, variables, strings and type conversion.
- Use lists and dictionaries to store and group data.
- Use conditions, loops and functions to organize program steps.
- Use modules, classes and objects to separate responsibilities.
- Validate simple user input and handle expected errors.

## Limitations

There is no permanent file storage, login, network connection, database or graphical interface. Due dates are stored as text and are not calendar-validated.
